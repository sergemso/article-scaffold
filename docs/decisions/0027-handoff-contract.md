## Decision

The delegator sends a brief (goal, scope, done-when); the agent replies with the result, then the evidence (commands run and their outcome, file references) (pack orchestration@0.1.1).

## Why

A fixed handoff keeps delegated context small and every result checkable (decision 0014).
